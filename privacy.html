Privacy Policy — KeePass Backup

Last updated: 2026-10-02

What the application does

KeePass Backup is a personal script that runs on its owner's computer and uploads an already encrypted KeePass database file to the owner's own Google Drive.

Data accessed

  • The application uses only the Google Drive drive.file scope, which allows access solely to files and folders created by the application itself.
  • It does not read, list or modify any other files in Google Drive.
  • It does not access email, contacts, profile data or any other Google account data.

Storage and sharing

  • No data is sent to any server other than Google's own APIs.
  • No data is collected, sold or shared with third parties.
  • The OAuth refresh token is stored only on the owner's computer, encrypted with Windows DPAPI.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
